注册登录

  • 用 /reg 密码 重复密码 来注册账号
  • 用 /loginplus unregister（不要轻易尝试！！！）来注销账号
  • 用 /login 密码 来登录（在已经注册过的状态下）

忘记密码

在已经将本账户登记过以后，可以用登记的应用来申诉。

家 相关

如何造一个家？你可以将房子的两个对角分别用木锄左键和右键，然后输入 /res create 家的名字（推荐用 用户名_home 来命名）来创建领地。

注：你需要挣钱。然后在家里一个安全的地方输入 /sethome 自定义名称，以后就可以 /home 名称 回家啦！

如果创建领地后忘设置家了，可以 /res tp 家的名字 来回家。

挣钱

目前系统商店还在研究中，你可以：

  1. 求别人给你，或者用 /pay 对方 ID 来送钱
  2. 与服务器交易
  3. 使用 /worth 测量手上的东西价值
  4. 用 /sell hand 数量 来卖东西（如果不熟悉经济插件，建议先将物品放在第一格来卖）

传送

  • 申请传送到别人那里：/tpa 对方玩家 ID
  • 申请别人传送到自己这里：/tpahere 对方玩家 ID
  • 传送回家：/home 家的名字

杂项

悄悄地对某人说话：/tell 对方玩家 ID
